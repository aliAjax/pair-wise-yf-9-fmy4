# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 复盘归档

聚完一局后点击详情里的「复盘归档」：

- 会快照当次的桌游资料（名称、人数、时长、复杂度、上次游玩、封面）和全部四类规则原文，生成一条独立归档；之后照常编辑收藏，旧归档仍读取归档时的原内容。
- 同一桌游可多次复盘，每次新增一份记录，不会覆盖前次。
- 每条规则可标记为「已解释清楚」或「仍会卡住」，并填写现场结论；没处理完的保持「待补」，可在记录里继续补充。
- 收藏列表卡片显示最近一次复盘的归档日期与两类结果数量（含待补数）；详情页的「复盘记录」列出全部归档，点进去可查看或继续编辑。
- 旧版本保存的数据会在打开时自动升级，补齐归档相关字段。
