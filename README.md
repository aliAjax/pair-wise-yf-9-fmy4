# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

## 复盘归档

聚完一局后，在详情里点「复盘归档」会把当前桌游资料和全部规则原样留底；之后照常编辑收藏，旧归档仍读取归档时的内容。同一桌游再次复盘会新增一份归档，不覆盖前次记录。打开归档可逐条标记「已解释清楚」或「仍会卡住」并写下现场结论；有未处理项时归档显示「待补」。收藏列表和详情都会显示归档日期与两类结果数量，旧版本收藏升级后自动补上归档功能。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
